# Anchor Protocol

> Anchor Protocol is a Terra-based decentralized finance (DeFi) savings protocol offering a low-volatility yield on Terra stablecoin (UST) deposits, borrowing against bonded-asset (bAsset) collateral, and cross-chain access via EthAnchor/xAnchor. Its developer surface is JavaScript/TypeScript SDKs and on-chain CosmWasm smart contracts rather than a REST or OpenAPI web API. Backed by Pantera Capital. Note: the protocol is associated with the Terra ecosystem and its main web application deployment is currently disabled.
